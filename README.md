# FlyingPlane

Ejercicio de Unity (abril de 2023): un avión que avanza solo y se inclina con las flechas arriba y abajo, con una cámara que lo sigue y una hélice que gira. La escena se llama `Challenge 1` y usa la `Course Library` de Unity, así que parte de un reto de los cursos de Unity Learn.

## Qué hay

- `PlayerControllerX.cs`: avance constante del avión e inclinación según el eje vertical.
- `FollowPlayerX.cs`: la cámara sigue al avión con un desplazamiento fijo.
- `SpinningPropeller.cs`: hace girar la hélice.
- `Assets/Scenes/Challenge 1.unity`: la escena del reto.

No lo he ejecutado desde aquí: Unity no está disponible en mi entorno de revisión, así que no he comprobado que abra y funcione.

## Cómo abrirlo

Abre la carpeta con Unity Hub usando la versión 2020.3.47f1 (u otra 2020.3 compatible) y carga la escena de `Assets/Scenes`.

# FlyingPlane (English)

Unity exercise (April 2023): a plane that flies forward on its own and tilts with the up and down arrow keys, with a camera that follows it and a spinning propeller. The scene is called `Challenge 1` and uses Unity's `Course Library`, so it starts from a challenge of the Unity Learn courses.

## What's inside

- `PlayerControllerX.cs`: constant forward motion and pitch driven by the vertical axis.
- `FollowPlayerX.cs`: the camera follows the plane at a fixed offset.
- `SpinningPropeller.cs`: spins the propeller.
- `Assets/Scenes/Challenge 1.unity`: the challenge scene.

I have not run it from here: Unity is not available in my review environment, so I have not checked that it opens and works.

## Opening it

Open the folder with Unity Hub using version 2020.3.47f1 (or another compatible 2020.3) and load the scene in `Assets/Scenes`.
